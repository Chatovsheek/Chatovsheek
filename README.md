### ⚙️ Go-разработка

Помимо веб-инструментов, пишу на Go. Репозитории:

*   **[Abandoned Server Scanner]([ссылка](https://github.com/Chatovsheek/abandoned-scan/))** - это утилита командной строки для поиска забытых и неиспользуемых серверов в сети. Она помогает администраторам и инженерам находить "бесхозные" узлы, которые могут быть забыты после миграций, тестов или экспериментов.

*   **[go-crypto-utils]([ссылка](https://github.com/Chatovsheek/go-crypto-utils/))** - это минималистичная библиотека для шифрования данных с использованием AES-GCM. Она предоставляет простой API для шифрования, дешифрования и работы с ключами.

*   **[Buffer Pool for Go]([ссылка](https://github.com/Chatovsheek/go-buffer-pool/))** —  go-buffer-pool — это пакет для эффективного управления буферами в Go. Он решает проблему частого выделения памяти при работе с потоками данных, сетевыми пакетами или любыми другими байтовыми операциями.
