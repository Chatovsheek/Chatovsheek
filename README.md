### Привет! Я разрабатываю инструменты для инженеров, математиков и не только.

Мой подход: **один HTML-файл — одно готовое приложение**. Открыл в браузере и работаешь. Без установки, без серверов, без лишних зависимостей. Файлы остаются на вашем компьютере.

### 🌐 Инженерные инструменты (DEEPPAG-DC)

Все три инструмента доступны онлайн (GitHub Pages) и для скачивания (Releases):

- **[Конвертер чертежей](https://chatovsheek.github.io/DEEPPAG-DC_drawing_format_converter/)** — DXF, SVG, PDF, PNG, JSON. Работает офлайн. [Исходники](https://github.com/Chatovsheek/DEEPPAG-DC_drawing_format_converter)
- **[Инженерный эскизник](https://chatovsheek.github.io/DEEPPAG-DC_engineering_sketchpad/)** — 2D-черчение, размеры по ГОСТ, рамка A4/A3, штамп. [Исходники](https://github.com/Chatovsheek/DEEPPAG-DC_engineering_sketchpad)
- **[Математический блокнот + графер](https://chatovsheek.github.io/DEEPPAG-DC_math-notebook_grapher/)** — LaTeX-формулы, графики функций (явные, неявные, параметрические), экспорт в PDF. [Исходники](https://github.com/Chatovsheek/DEEPPAG-DC_math-notebook_grapher)

### ⚙️ Go-разработка

Помимо веб-инструментов, пишу на Go. Репозитории:

- **[Abandoned Server Scanner](https://github.com/Chatovsheek/abandoned-scan)** — утилита командной строки для поиска забытых и неиспользуемых серверов в сети. Помогает администраторам и инженерам находить «бесхозные» узлы, которые могут быть забыты после миграций, тестов или экспериментов.
- **[go-crypto-utils](https://github.com/Chatovsheek/go-crypto-utils)** — минималистичная библиотека для шифрования данных с использованием AES-GCM. Простой API для шифрования, дешифрования и работы с ключами.
- **[go-buffer-pool](https://github.com/Chatovsheek/go-buffer-pool)** — пакет для эффективного управления буферами в Go. Решает проблему частого выделения памяти при работе с потоками данных, сетевыми пакетами или любыми другими байтовыми операциями.

*(Все Go-проекты распространяются под GNU GPL v3.0.)*
